# Real-Time Face Mask Detection (3-Class)

This project is a real-time face mask detection system built using MobileNetV2 and OpenCV. It classifies faces into three categories: Correctly Worn, Incorrectly Worn, and No Mask.

## How to Run
1. Install dependencies: `pip install tensorflow opencv-python numpy Pillow scipy`
2. Run the webcam script: `python inference.py`
